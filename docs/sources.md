This distribution contains independently drafted protocols, project-local Python and self-owned fixtures; it does not vendor the reference projects, rulesets, articles, translations or images. A bounded inventory identified no included third-party portion requiring a separate NOTICE; this is not exhaustive originality or legal clearance. Before substantial copying, inspect the exact upstream files and retain applicable notices/terms.

The primary inspiration is [How the Claude Code team does code review](https://claude.dev/blog/solving-code-review-at-anthropic/). Its whole text, translations and images are excluded. A code repository's license cannot license an unrelated article; attribution or a link does not grant reproduction permission. Private input, archive, logs and internal review history are not release content.

Method references below were read as design inputs, not installed dependencies or independent proof of effectiveness. The project's evidence, authorization and stop rules prevail over their defaults.
